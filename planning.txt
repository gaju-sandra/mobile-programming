### 1. [freeCodeCamp](https://www.freecodecamp.org/?utm_source=chatgpt.com) — Start here

This is probably the best place for you right now.

You can learn:

* JavaScript
* APIs
* Node.js
* Express
* Databases
* Backend development
* React
* Algorithms
* Git/GitHub

Since you're already learning JavaScript, I would continue there before jumping into backend.
